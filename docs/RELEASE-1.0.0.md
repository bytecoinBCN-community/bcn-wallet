# BCN Wallet 1.0.0

Desktop wallet for Bytecoin (BCN) on Windows 10/11 — with or without downloading the blockchain.

**Downloads**

| File | What it is |
| --- | --- |
| `BCNWallet-1.0.0-setup.exe` | Installer: per user, no administrator rights, Start menu / desktop shortcuts, uninstall from Settings → Apps |
| `BCNWallet-1.0.0-win-portable.zip` | Portable: unpack anywhere and run `BCNWallet.exe`; everything stays in the `data` folder |
| `SHA256SUMS` | Checksums of both files |

Both include the official, unchanged `walletd.exe` and `bytecoind.exe` 3.5.1 from https://github.com/bcndev/bytecoin/releases/tag/v3.5.1 (archive SHA-256 `daa6a8a3b5c3aec7abc05a1f001abe1c0afd2d540ae7cb8fe9dc6dfdb72aec96`). The programs are not code-signed, so Windows SmartScreen may ask for confirmation on first start.

**Highlights**

- Two modes: without the blockchain through the community node `node.bytecoin.community` (ready in minutes), or a full node with its own bytecoind (about 45 GB).
- Create (24 words), restore (with optional date), open `.wallet`, import keys of old `2…` wallets.
- Send with fee levels and payment ID, receive with QR code, history with search, address book, view-only export, password change.
- Community page: BCN Miner, community pool, explorer, web wallet, Telegram.
- Dark and light themes; Українська, English, Español, Português, Türkçe, Bahasa Indonesia, Tiếng Việt, 中文.

# BCN Wallet 1.0.0 (українською)

Настільний гаманець Bytecoin (BCN) для Windows 10/11 — із завантаженням блокчейну або без нього.

- `BCNWallet-1.0.0-setup.exe` — інсталятор: лише для вашого користувача, без прав адміністратора, ярлики, видалення через «Параметри → Програми».
- `BCNWallet-1.0.0-win-portable.zip` — портативна версія: розпакуйте будь-куди й запустіть `BCNWallet.exe`; усе зберігається в папці `data`.
- `SHA256SUMS` — контрольні суми.

Усередині — офіційні незмінені `walletd.exe` і `bytecoind.exe` 3.5.1 від bcndev. Програми не мають цифрового підпису, тож SmartScreen може попросити підтвердження під час першого запуску.

Два режими: без блокчейну через вузол спільноти `node.bytecoin.community` (готово за кілька хвилин) або повний вузол із власним bytecoind (близько 45 ГБ). Створення, відновлення з 24 слів, відкриття файлів `.wallet`, імпорт ключів старих гаманців; надсилання з комісією та Payment ID, отримання з QR-кодом, історія, адресна книга, експорт копії для перегляду, зміна пароля; сторінка спільноти з BCN Miner, пулом, експлорером, веб-гаманцем і Telegram. Темна й світла теми, 8 мов.
